# 暗色主题页面设计规范

这些规则来自多轮改版里用户的明确反馈：信息不要挤；颜色要克制；标题和其他页面用同一套字体；按钮风格统一；能折叠的文字都折叠起来。新页面一开始就按这些来，可以省掉好几轮返工。

## 配色

| 用途 | 色值 |
|---|---|
| 页面底色 | `#181A20` |
| 面板、卡片 | `#1F222A` |
| 面板里的卡片、浮层 | `#262A34` |
| 次级按钮、分隔线 | `#35383F`、`#30343E` |
| 首屏深底 | `#121419` |
| 品牌红 | `#DC0000`（按下 `#B80000`；红色文字用 `#FF4D4D` 或 `#FF6B6B`；浅底用 `rgba(220,0,0,.12)`） |
| 文字：正文 / 次要 / 弱化 | `#FFFFFF` / `#9CA3AF` / `#6B7280` |
| 金色 | `#F4B740` |
| 象牙白 | `#F2F2EE`、`#F3EEE6` |
| 状态色 | 进行中 `#3FCF84`，提醒 `#FFC53A`，停止 `#FF5646` |

- **一屏只有一个强红色焦点**，通常是主按钮。标题用白色；红色只留给按钮、当前步骤、提示箭头这类「可以点」「正在发生」的东西。
- **辅助色从首屏图片里取**。比如平台认证页功能特权的三组颜色，取自海报的台呢绿、筹码蓝、橘猫橙。辅助色只用在图标和小面积强调上，图标块保持中性底色。
- **选中态**：只加一圈分组色描边和浅底色，不要整块填满。

## 字体

- **标题字体**（`ZZDisplay`）用于页面大标题、区块标题、比赛名、海报标题。同一类标题在所有页面用同一套字体，这是用户明确要求过的。新增标题文字时记得补字体子集（见 `font-icon-pipeline` 技能）。
- **数字**（`BoardNum`）：大号指标用 200 细体，翻牌和时刻表用 700/800。
- **正文**：系统字体。
- **参考字号**：页面大标题 64rpx，区块标题 40rpx，分组标题 32～34rpx，正文 26～28rpx，辅助说明 22～24rpx。

## 布局

- 左右边距 40rpx，区块间距 88～96rpx，卡片圆角 28～32rpx，按钮和标签用胶囊圆角。
- **标题区**：大标题左对齐，和返回按钮同一行；说明、规则这类操作图标紧跟在标题右侧。右上角永远留给微信的胶囊按钮。
- **首屏可以用编辑式排版**：左侧竖排标语加一条细线；右侧大图贴着屏幕右边缘，底部渐隐到页面底色；一个强调块压住大图的一角。照片一律用 `<image>` 组件加载。
- **长页面**：首屏之后用一块圆角面板承接内容；滚过大标题后出现紧凑标题栏；滚到底时用底部按钮换下导航栏。

## 信息密度

- **默认只显示标题，说明点开再看**：常见问题整组折叠成一行；权益和特权点某一项才展开说明；同一时间只展开一段。
- **不用表格做对比**：把「之前 → 之后」放进对应的条目里。涉及头像时直接放头像，比如认证后在头像右下角加 V 标识。
- **留白优先于加框**：数据指标只留数字，不套卡片。

## 组件

- **主按钮**：红色胶囊，`#DC0000`，带红色投影，白色文字，可以带一个小箭头。全站统一，不用描边方框。
- **次级按钮、状态按钮**：`#2A2D36` 或 `#35383F`，比如「查看进度」「管理认证」。
- **认证标识**：头像右下角一个红色圆点，里面是白色的 V；外圈描边用所在卡片的底色。
- **多状态页面**：每种状态（例如未认证、审核中、已认证、未通过）都要设计好标题、说明、按钮文案和颜色，并给开发预览留一个 URL 参数。

## 文案与合规

- 不出现赌博相关的说法（项目已经把「德扑」类文案替换掉），不出现积分或筹码兑换现金。
- 文案、规则、指标先放在 mock 文件里，并标明是草稿；数据指标上线前必须是真实统计，并写明统计口径。
- 用户提供的图片，要提醒确认商用版权；扑克牌、筹码这类画面，要提醒可能影响小程序审核。

## 照参考稿改版

逐个区域对照草图：每一块是什么、放在哪、和谁重叠。和草图不一致的地方（比如胶囊按钮挡住了右上角），要说明怎么处理的、为什么这样处理。改完用截图拼图对照检查（见 `uniapp-h5-regression` 技能）。
